# Hearth wire protocol

The wire protocol is specified normatively in
[`spec/protocol-v1.md`](../spec/protocol-v1.md), the schema-document format used
by code generators in [`spec/schema-v1.md`](../spec/schema-v1.md), and what
semver covers in [`spec/stability.md`](../spec/stability.md). Third-party SDKs
verify themselves with the conformance kit in
[`conformance/`](../conformance/README.md).
